# Changelog

All notable changes to this project will be documented here.

## 0.1.1 - 2026-09-05

- Add `/obsidian-setup` to create missing global configuration files from interactive vault path prompts without overwriting existing settings.
- Guide new installations to setup and keep broad Obsidian tools disabled when global knowledge configuration is absent.

## 0.1.0 - 2026-08-21

- Capture finalized Pi question-and-answer exchanges in append-only Obsidian notes.
- Distill sessions into curated project notes with provenance and MOC linking.
- Add repository-scoped `project_knowledge` status, search, and read actions.
- Add access modes, budgets, path confinement, symlink checks, and exact-ref reads.
- Add commands for context initialization, source linking, capture control, and broad Obsidian tool gating.
